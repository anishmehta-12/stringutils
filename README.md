# stringutils

A tiny collection of string utility functions.

## Functions

- `reverse_words(text)` — reverse the order of words in a string.
- `title_case(text)` — capitalize the first letter of every word.
- `is_palindrome(text)` — check whether a string reads the same forwards and backwards, ignoring case, spaces, and punctuation.

## Tests

Run the test suite with:

```bash
pytest
```
